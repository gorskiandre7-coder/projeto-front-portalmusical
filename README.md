# Portal Musical | SoundWave

Esse projeto foi desenvolvido em dupla como um trabalho avaliativo da faculdade, na matéria de Desenvolvimento Front-End Para Web.

A ideia foi criar um portal musical onde as pessoas pudessem encontrar informações sobre artistas, álbuns, lançamentos e diferentes estilos musicais.

Para desenvolver o projeto, utilizamos HTML, CSS e JavaScript, colocando em prática os conteúdos que foram ensinados durante as aulas.

## Tecnologias utilizadas

- HTML5 (Estrutura semântica e tabelas)
- CSS3 (CSS Grid e responsividade)
- JavaScript (Manipulação do DOM e validação de formulários)

## Sobre o projeto

O site possui diversas seções, como lançamentos, álbuns, perfil de artista e gêneros musicais. Também desenvolvemos funcionalidades para deixar a página interativa, como carrossel de álbuns, fila de reprodução, janela modal de envio de demo e validação de formulário VIP.

Durante o desenvolvimento, utilizamos ferramentas de inteligência artificial como apoio consultivo, principalmente para tirar dúvidas, entender partes do código e receber explicações sobre determinadas funcionalidades. A ideia foi utilizar esse auxílio para aprender e compreender melhor o que estava sendo desenvolvido.

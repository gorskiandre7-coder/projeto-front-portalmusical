# Portal Musical

Esse projeto foi desenvolvido como um trabalho avaliativo da faculdade, na matéria de Desenvolvimento Front-End Para Web.

A ideia foi criar um portal musical onde as pessoas pudessem encontrar informações sobre artistas, álbuns, lançamentos e diferentes estilos musicais.

Para desenvolver o projeto, utilizei HTML, CSS e JavaScript, colocando em prática os conteúdos que foram ensinados durante as aulas.

## Tecnologias utilizadas

- HTML

- CSS

- JavaScript

## Sobre o projeto

O site possui algumas seções, como lançamentos, álbuns, artistas e gêneros musicais. Também desenvolvi algumas funcionalidades para deixar a página mais interativa, como carrossel de álbuns, fila de reprodução e formulários.

Durante o desenvolvimento, também utilizei ferramentas de inteligência artificial como apoio, principalmente para tirar dúvidas, entender algumas partes do código e receber explicações sobre determinadas funcionalidades. A ideia foi utilizar esse auxílio para aprender e compreender melhor o que estava sendo desenvolvido.

Foi um projeto interessante para praticar o que venho aprendendo e entender melhor como funciona o desenvolvimento de uma página web.
